# Credits

This program is a compiled reimplementation of the
[`update_flatpak_cli.py`](https://gist.github.com/ssokolow/db565fd8a82d6002baada946adb81f68)
gist by **Stephan Sokolow (deitarion/SSokolow)**.

That original work is copyright © 2021-2022 Stephan Sokolow and distributed
under the MIT licence. The following parts of this project are derived from it:

* the five command-name derivation heuristics and the order they are applied in,
* the built-in remapping table (`CMD_REMAPPINGS`) and secondary-command table
  (`EXTRA_COMMANDS`),
* the behaviour of the generated launcher, including the `--file-forwarding`
  argument rewriting and the `LD_PRELOAD` workaround,
* the marker line `# AUTOGENERATED FILE! DO NOT EDIT!` written into every
  launcher, which also lets this version clean up launchers created by the
  Python original,
* the `$PATH` diagnostics, and the "add a CMD_REMAPPINGS entry" advice.

The implementation here (Nim, on-disk Flatpak discovery instead of PyGObject,
plus the safety and correctness fixes listed in the README) is released under
the MIT licence; see [LICENSE](LICENSE).
